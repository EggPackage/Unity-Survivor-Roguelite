## 一、这个原型是什么

《暮色调配师》(DawnBrewDuskSpirit) 是"早咖晚酒"复合循环游戏(GDD 在 `Assets/docs/DawnBrewDuskSpirit-GDD.docx`)。三大玩法：白天咖啡厅经营、**下午顶视角肉鸽砍杀**、深夜叙事。

白天经营(`Assets/Scripts/Game/Bar/`)已有数据驱动实现。**本次目标 = 从零搭出"下午地牢"的最小可玩战斗闭环**：玩家能移动、能挥砍("拉花剑气")、敌人会追击、命中有顿帧+震屏硬核反馈、敌人会死会刷。

Tiny Swords 素材(`Assets/Tiny Swords/`)当**临时占位**，以后换正式美术，所以逻辑层与占位美术解耦。

### 三项已确认决策
1. **输入**：复用项目自研旧版 `InputMgr` + `EventCenter`，**不引入新版 Input System**。
2. **主角占位**：Tiny Swords `Blue Warrior`(精灵已切帧、自带 controller)，横版精灵靠 **Visual 子节点 FlipX 面向鼠标**。
3. **范围**：核心战斗闭环(移动+近战+敌人 AI+顿帧+震屏+简单刷怪)，暂不接 Bar 的 Build 联动、暂不上 URP。
