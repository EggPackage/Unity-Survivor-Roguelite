## 1. 新增文件（7 个）

### 1.1 `Assets/Scripts/Game/Dungeon/Input/DungeonInput.cs`（79 行）— T1 输入意图层

| 行 | 内容 | 标注 |
|---|---|---|
| 25 | `public static class DungeonInput` | 静态类，无实例、无场景依赖，谁都能订阅 |
| 27–29 | `OnMove` / `OnPause` / `OnRestart` 三个事件 | **对外全部契约**。业务层只认这三个，永远看不到 `KeyCode`/`InputAction` |
| 31–32 | `_map` / `_initialized` | 内联 `InputActionMap`，懒初始化（第一次 `EnsureEnabled` 才建） |
| 35 | `Init()` | 建 map、加 Move/Pause/Restart 三个 action、绑 WASD + 手柄左摇杆 + Esc + R |
| 73 | `EnsureEnabled()` | 幂等入口：`Init` + `Enable`。订阅方在 `OnEnable` 调一次即可 |

**为什么用内联 map 而不是 `.inputactions` 资产**：零资产依赖、首编译即用、不会踩"生成类还没生成"的时序坑。代价是改键不能可视化（M3 补，对外契约不变）。

## 4. 你自己核对改动的命令

```bash
git log --oneline -3                          # 看两次提交
git show 5f1f64c --stat                       # M1 提交改了哪些文件
git show 5f1f64c -- Assets/Scripts/Game/Dungeon/Player/DungeonPlayerController.cs   # 单文件完整 diff

git status                                    # 应显示 clean
```

在 Unity 里对照看代码时，用 Rider/VS 的 Git 面板会比命令行快：右侧 gutter 上的绿/蓝竖条就是改动行，点一下能看原始版本。
